## Expected Format

Each CSV file should contain:

- one row per valid configuration
- one column per configuration option
- a final `performance` column giving the measured runtime or other objective value

The final coursework experiments use the included `7z.csv`, `LLVM.csv`, and `x264.csv` files directly.
